# Baton — Handoff Brief · public pages

This repository serves the public documents for **Baton — Handoff Brief**, a Jira app by Gaon Lab, entered in Atlassian's Codegeist 2026 hackathon (category: *Apps for Software Teams*).

It is a static site published with GitHub Pages. No scripts, fonts or analytics are loaded from anywhere.

**What the app does:** it reads a Jira issue's own record — comments, field changes, links — and writes the handoff brief: what was decided, what is blocked, what is still open, and who knows the history. Every line quotes a real comment with its author and date; nothing is generated by a language model.

**Data handling:** no storage, no external egress, no analytics. Requests run as the signed-in user (`asUser()`), so Jira's own permissions decide what the app can read. Scopes: `read:jira-work`, `read:jira-user`, `write:jira-work`.
